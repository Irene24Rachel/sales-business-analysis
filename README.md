# Sales Business Analysis

A data analysis project using Python and Power BI to explore sales
performance, identify trends, and generate actionable business insights.

## 📌 Project Overview

This project focuses on analyzing sales data to understand business
performance across different products, customers, regions, and time periods.

Python is used for data cleaning, preprocessing, exploration, and analysis,
while Power BI is used to create interactive dashboards and visualize
important business metrics.

## 🎯 Objectives

- Clean and preprocess sales data
- Perform exploratory data analysis
- Identify sales trends
- Analyze product performance
- Analyze regional performance
- Identify important business patterns
- Create interactive Power BI dashboards
- Generate actionable business insights

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Microsoft Power BI
